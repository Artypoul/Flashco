## Принятые решения

- На новой установке включать TUN и автоматическую маршрутизацию; существующие настройки не перезаписывать при каждом запуске. Внешний API по умолчанию закрыт.
- После успешного импорта выбирать и запускать сохранённый профиль с сохранением приоритета более поздней остановки.
- Российские домены/IP направляются через редактируемые правила `DIRECT`. Начальные правила создаются для новой базы, недостающие российские правила также добавляются однократной миграцией с сохранением правок пользователя.
- Пять китайских исключений удалены из исходных правил и старых настроек однократно. Повторно добавленные пользователем исключения не удалять при каждом запуске.
- Firebase Analytics и Crashlytics удалены; локальная обработка сбоев сохранена. Проверка качества IP и Android QR-сканер Google ML Kit оставлены по решению Артёма; исключение по диагностике раскрыто в соглашении.
- Соглашение принимается одной кнопкой «Согласен», без проверки прокрутки или повторения фразы. В «О приложении» и соглашении — бесплатный некоммерческий продукт; исходные лицензии сохраняются.
- На простом экране — большая кнопка подключения и компактное добавление конфигурации. Светлая тема и подключение при запуске включаются персональными значениями по умолчанию один раз; ручные настройки сохраняются.
- Персональные Windows/Android workflow получают обязательный ручной `subscription_url` и передают его в `BOOTSTRAP_SUBSCRIPTION_URL`. Подписка сохраняется и импортируется однократно; после удаления профиля пользователем повторно не добавляется.
- По явному выбору пользователя восстановлена логика версии `da07f58a` до новых режимов fallback и Safe. Исходный интервал автообновления подписок — сутки; уже сохранённые интервалы не переписываются откатом исходников.
